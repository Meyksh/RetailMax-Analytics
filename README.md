# RetailMax-Analytics

Análisis comercial: Proyecto de análisis de datos orientado a mejorar las ventas de retailmax.
El objetivo es identificar patrones, tendencias y oportunidades de mejora en el desenpeño comercial, apoyando la toma de decisiones basada en datos.
